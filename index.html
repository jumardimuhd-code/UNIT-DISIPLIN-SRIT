Integrasi Senarai Murid (Google Sheet)

Status: Belum disambung

Tampal pautan Google Sheet anda untuk memuatkan senarai nama murid dan kelas secara automatik pada borang pendaftaran.

Cara Mudah Dapatkan Pautan Google Sheet:

1. Buka Google Sheet murid → Pastikan Lajur A = Nama Murid dan Lajur B = Kelas.

2. Klik menu Fail (File) → Kongsi (Share) → Terbitkan ke web (Publish to web).

3. Pilih helaian murid, tukar format ke Comma-separated values (.csv) → Klik Terbitkan (Publish).

4. Salin pautan yang diberi dan tampal di kotak atas!
